# Instruction Template: Bugfix

Use this template for debugging and fixes.

## Required process
1. Reproduce issue with clear steps.
2. Identify root cause (not just symptom).
3. Implement minimal fix.
4. Add or update validation to prevent recurrence.
5. Document behavior change if externally visible.

## Required output
- Root cause summary
- Files changed
- Validation evidence
- Remaining risks or follow-up tasks
