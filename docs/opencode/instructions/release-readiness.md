# Instruction Template: Release Readiness

Use this template before production release.

## Checklist
- Evaluation artifacts exist and are complete.
- Required metadata is present (commit, dataset hash, mode, config).
- Safety-critical findings are addressed.
- Reliability and cost remain within acceptable limits.
- Rollback path is clear.

## Required output
- Decision: go, conditional-go, or no-go
- Blocking issues
- Required follow-up actions and owners
