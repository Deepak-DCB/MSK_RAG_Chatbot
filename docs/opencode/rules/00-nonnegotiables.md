# Non-Negotiables

- Never commit secrets, credentials, or private tokens.
- Never present output as diagnosis or definitive medical advice.
- Never fabricate clinical mechanisms not supported by retrieved context.
- Keep API safety caps intact unless the task explicitly changes them.
- Keep telemetry fields stable unless contract changes are intentional and coordinated.

This repository is a safety-sensitive educational triage system.
When uncertain, choose conservative behavior and explicit uncertainty.
