# Clinical Context: Thoracic Outlet Patterns

Thoracic-outlet-like patterns in this project are evaluated through biomechanics and space relationships.

Key reminders:
- Relevant loading can involve both interscalene and costoclavicular regions.
- Scapuloclavicular position, first-rib mechanics, and breathing behavior all matter.
- Muscle state may vary by pattern; do not force one generic explanation.

Output expectations:
- Use conservative, mechanism-level explanation.
- Include uncertainty when evidence is mixed.
- Escalate when red-flag features are present.
