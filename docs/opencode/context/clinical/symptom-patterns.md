# Clinical Context: Symptom Patterns

Core triage framing should separate:
1. Non-specific overload or postural discomfort
2. Structured biomechanical patterns
3. Potentially concerning red-flag patterns

For non-specific patterns:
- Keep explanations simple.
- Prefer low-intensity conservative guidance.

For structured biomechanical patterns:
- Explain orientation, movement quality, neural or vascular load, compensation, and practical correction order.

For concerning patterns:
- Prioritize safety escalation and in-person evaluation guidance.
